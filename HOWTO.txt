INSTALL
================================================================================

  From source:
    git clone https://github.com/OldGrowthCrypto/SolanaPrice-Tracker.git
    cd SolanaPrice-Tracker
    ./setup.sh
    gnome-extensions enable price-tracker@oldgrowthcrypto.com

  From extension zip:
    gnome-extensions install -f ./oldgrowth-price-tracker.shell-extension.zip
    gnome-extensions enable price-tracker@oldgrowthcrypto.com

  Reload Shell:
    Wayland → log out / in
    X11     → Alt+F2, type r, Enter


================================================================================
DASHBOARD
================================================================================

  Header
    · App name: Solana Crypto Price Tracker
    · Subtitle: Tracking your favorite Solana tokens
    · Refresh button

  Watchlist
    · Drag ☰ or use ↑↓ to reorder (order = top-bar priority)
    · Fits rows tightly (no empty gap under last coin)
    · Scroll only when more than 5 coins

  Each coin row
    · Price + 24h change
    · Edit · Alerts (bell) · Chart · Jupiter swap · Copy · Bar switch · Trash
    · BTC: swap opens portal wrapped BTC on Solana (SOL pair on jup.ag)
    · Coins without a mint show dimmed copy/swap placeholders for alignment

  Status strip
    · Updated · coin count · bar n/max · alerts summary

  Action bar (bottom, side-by-side)
    · Add token  → add pair or Solana contract
    · Options    → display, refresh, chart default, watchlist tools
    · Website    → oldgrowthcrypto.com


================================================================================
PER-COIN ALERTS (bell icon)
================================================================================

  · Enable alerts for that coin only
  · Separate % for pump (up) and dump (down)
  · Presets 1–10% or type a custom value
  · Chart preference: DexScreener / Birdeye / Jupiter
  · Open chart · Swap on Jupiter (SOL)
  · Save

  Alerts fire on quick moves between price refreshes (not 24h change).
  Cooldown reduces spam (default 120s, Extension Settings → Alerts).


================================================================================
OPTIONS (compact)
================================================================================

  Top bar: Icons · Tickers · Colorize · Max on bar chips
  Refresh: 20s–90s chips + Now
  Chart:   Dex / Birdeye / Jup default
  Watchlist: Export · Import · Reset · Debug + JSON path

  Price triggers are NOT in Options — use the bell on each coin.


================================================================================
ADD TOKEN
================================================================================

  Add by pair (e.g. BONK/USD) or paste a Solana mint (base58).
  Mint preview shows symbol, name, price, 24h before you confirm.


================================================================================
TROUBLESHOOTING
================================================================================

  journalctl -f -o cat /usr/bin/gnome-shell | grep OldGrowthPriceTracker

  Recompile schemas after schema changes:
    glib-compile-schemas \
      ~/.local/share/gnome-shell/extensions/price-tracker@oldgrowthcrypto.com/schemas/

  Extension not listed: log out (Wayland) or restart Shell (X11).
