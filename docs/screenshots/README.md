# Screenshots for GNOME Extensions & GitHub

Place PNG files here when capturing release media (not required inside the zip).

## Recommended filenames

| File | Content |
|------|---------|
| `01-panel-light.png` | Top bar chips, light GNOME theme |
| `02-panel-dark.png` | Top bar chips, dark theme |
| `03-dashboard.png` | Popup dashboard with 5 coins visible |
| `04-options-alerts.png` | Options modal showing jump alerts |
| `05-prefs-alerts.png` | Extension Settings → Alerts page |

## Capture tips

1. Use a clean desktop; hide unrelated panel icons if possible.  
2. Include SOL + a couple of ecosystem tokens so Solana branding is obvious.  
3. For the dashboard shot, show the **WATCHLIST** label and drag handles.  
4. Prefer **1920×1080** full desktop or a tight crop of the panel + popup.  
5. Do not include personal wallet addresses or private info.

These images are for the **extensions.gnome.org** listing and GitHub README —  
they do not need to be shipped inside `*.shell-extension.zip`.
